# The Mentalist — ใครคือฆาตกร?

เว็บสรุปคดีของซีรีส์ *The Mentalist* ครบทั้ง **7 ซีซัน 151 ตอน** — ระบุตัวฆาตกร แรงจูงใจ เหยื่อ และสรุปเหตุการณ์ในแต่ละตอน พร้อมเส้นเรื่องหลัก Red John

## ฟีเจอร์
- ค้นหาข้ามทุกตอน (ชื่อตอน / ฆาตกร / แรงจูงใจ / เหยื่อ)
- กรองตามซีซัน
- โหมดกันสปอยล์: ชื่อฆาตกรถูกเบลอไว้เป็นค่าเริ่มต้น (ชี้เมาส์เพื่อดูทีละอัน หรือกดสวิตช์เปิดทั้งหมด)
- แท็กตอนที่เป็นเส้นเรื่อง Red John

## โครงสร้าง
- `index.html` — หน้าเว็บทั้งหมด (ไม่มี build step)
- `data.js` — ข้อมูลทั้ง 151 ตอน
